Twelve days ago I wrote that Voxcade was a prototype in a private
repository and that there was nothing to download yet. Today there is.
Voxcade 0.4.2 is out for Windows and Linux, it is free under the zlib
licence, and the [source is on GitHub](https://github.com/SACRVM/voxcade).
The downloads, how to install and a quick start live on its own site,
[voxca.de](https://voxca.de/).

# What you get

One folder. Nothing to install: unpack it and start Voxcade.

- **The launcher.** It lists the games. PLAY starts one, EDIT opens it in
  the IDE, and NEW GAME begins one of your own from a template: a jump &
  run, a shooter, or empty.
- **Five games**, each a folder of Lua and voxels, each in another genre:
  More Blood, a desert run'n'gun; Voxkeep, a jump & run in a castle at
  night; Sokovox, Sokoban with David W. Skinner's 155 Microban puzzles;
  Pulsar, a space shooter whose waves come on the song's bars, for two;
  and BunnyFarm, a farming game with a whole farm year, in German, English
  and French.
- **The IDE.** The code with the API's names offered as you type, the game
  playing right beside it, its errors pointing at the line. Scenarios that
  start a run anywhere, editors for voxel models and for levels of blocks,
  HELP with the API by example, BUILD to pack a game for passing on — and
  a console with Claude Code in it, one conversation per game, seeing the
  IDE over MCP.
- **Playing together.** Up to four at one screen, as at an arcade machine.
  On the home network, or across the internet by a code of six signs,
  like `DX67A3`: send it in the chat, no ports to open, and friends can
  join a game already running.
- **New versions by themselves.** The launcher says when one is there,
  and UPDATE NOW fetches it, checks its checksum and puts it in place.
  Your games, settings and saves stay.

# Free, and open

Voxcade is under the zlib licence, the one [LÖVE](https://love2d.org/)
has, and LÖVE showed the way for more than the licence. Use it for
nothing, make games with it, give them away or sell them: a game you make
with Voxcade is yours. The five games and the templates come under the
same terms, to learn from and to build on.

The engine, the games, the IDE and the tools are all in the
[repository](https://github.com/SACRVM/voxcade). Pull requests are
welcome; `CONTRIBUTING.md` says what to check first. A bug report helps
most with a replay attached: F9 keeps the run you just played, and since
every run plays the same way every time, the replay *is* the bug.

# The part that finds the other players

Playing across the internet needed something in the middle: a place where
a host opens a room and gets its code, where guests find the room by that
code, and a relay for the machines whose routers will not let them reach
each other. That is [matchmaker](https://github.com/SACRVM/matchmaker), a
program of its own and public too. It has no accounts and no database — a
room lives exactly as long as its host stays connected — and it can run
under [Husky](https://github.com/SACRVM/husky), which keeps it up and
installs its new releases. It was made for Voxcade and is meant for any
peer-to-peer game, in any engine: over iroh, or over a WebSocket from a
browser, Unity, Godot or anything else.

# Still built for agents

Nothing from the [first post](/blog/2026-10-29-voxcade.html) went away
on the way to a release. Everything in a game is text, the simulation is
deterministic down to the bit, and every game keeps scenarios that begin a
run late. So the command line can play a game without a window and show
what happened:

```bash
voxcade shot games/voxkeep --frames 120 --input "right:60;right+jump:20" --out x.png
voxcade inspect games/sokovox --frames 300 --input "up:20;left:40"
voxcade check games/bunnyfarm
```

A picture, the game's state as JSON, every replay checked against how it
was recorded. `voxcade mcp` hands the same to an agent as tools. That is
how a game is tested here, and how an agent sees what it built.

# Good to know

- **Windows** may warn that it protected your PC: the program is not
  signed yet. *More info*, then *Run anyway*.
- **Linux** needs Vulkan drivers and a current system: Ubuntu 24.04,
  Linux Mint 22, Fedora 40, Debian 13 or later.
- **macOS** is not part of this release; it builds from source.
- **Version 0.4** means what it says: early, and in use. The Lua API may
  still change before 1.0.

What comes next: ready-made rules for more genres — RPGs, adventures,
strategy, racing — and a game jam mode, up to four people typing in the
same files of one IDE while an agent builds what the group agreed on.

Voxcade is free and stays free. If it is useful to you, there is
[GitHub Sponsors](https://github.com/sponsors/SACRVM) — but making a game
with it and showing it helps more than anything.
